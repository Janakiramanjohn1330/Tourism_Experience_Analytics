🌍 Tourist Attraction Recommender
📌 Overview

This project builds a machine learning-powered recommender system for predicting and analyzing tourist preferences across different destinations. It integrates classification models (for predicting visit modes) and regression models (for forecasting ratings), along with EDA visualizations to uncover travel patterns. The project is deployed with a Streamlit dashboard.

🚀 Features

* Classification Models – Predict visit modes using Random Forest, Logistic Regression, XGBoost, and LightGBM.

* Regression Models – Forecast tourist ratings with Linear Regression, Random Forest, Decision Trees, and Gradient Boosting.

* Exploratory Data Analysis (EDA) – Insights on user distribution across countries/regions, attraction ratings, and continent-wise patterns.

* Interactive Streamlit App – Tabs for Introduction, Classification, Regression, and EDA.

🔄 Steps

* Data Preprocessing – Handle missing values, encode categorical features.

* Classification – Train ML classifiers and evaluate with Accuracy, F1 Score, and Recall.

* Regression – Train regression models and evaluate with MSE, MAE, R².

* EDA – Visualize user distribution, attraction types, and regional trends.

* Deployment – Build a Streamlit app for end-user interaction.

🛠 Tools

* Python (Pandas, NumPy, Scikit-learn, XGBoost, LightGBM)

* Streamlit

* Matplotlib & Seaborn (for EDA visualizations)

✅ Skills Learned

* Classification & Regression Modeling

* Model Evaluation (Accuracy, F1, Recall, MSE, MAE, R²)

* Exploratory Data Analysis & Visualization
